CtrLang

Türkçe Backend Web Dili

curl -fsSL https://darking053official.github.io/CtrLang/install.sh | sh
GitHub'da Gör İndir

Nedir?

CtrLang, Türkçe anahtar kelimelerle yazılan bir backend web dilidir. PHP ve Node.js'in Türkçe alternatifi olmayı hedefler.

sunucu başlat(3000) sayfa "/" { yazdır "Merhaba CtrLang!" }

Özellikler

Türkçe Sözdizimi

Kod yazarken kendi dilinde düşün: yazdır, eğer, döngü, işlev

Saf C

Hızlı, hafif (~2 MB bellek).

SQLite

Yerleşik veritabanı. Harici sunucu gerekmez.

HTTP Sunucu

Mongoose ile gerçek web sunucusu.

HTML + JSON

Yerleşik üretim. html { } ve json { } blokları.

Çapraz Platform

Linux, macOS, Windows, Android (Termux).

Kurulum
